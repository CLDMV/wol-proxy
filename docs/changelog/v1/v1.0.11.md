# wol-proxy v1.0.11 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

A dev-tooling dependency release: Vitest and `@vitest/coverage-v8` move from 5.0.2 to 5.0.3, along with the Vite and Rolldown packages Vitest depends on. The net change against v1.0.10 is `package.json` (the version field only) and `package-lock.json`.

No runtime code changed. `index.js`, `postinstall.js` and `wol-proxy.service` are exactly as in v1.0.10, the runtime dependencies (`express` `^5.1.0`, `wake_on_lan` `^1.0.0`) and their lockfile entries are unchanged, and every package that moved is a development dependency. `@cldmv/vitest-runner` is already at 1.5.3 on v1.0.10, so the Node.js 22 requirement of its `chalk` 6 dependency is not new in this release.

---

## 🔧 Dependencies

All dev-only; nothing that ships depends on them. The `package.json` ranges (`vitest` and `@vitest/coverage-v8` `^5.0.0`) are unchanged, so only the lockfile moved.

- **`vitest` and `@vitest/coverage-v8` 5.0.2 → 5.0.3**, with `@vitest/mocker` and `@vitest/spy` at 5.0.3 ([#42](https://github.com/CLDMV/wol-proxy/pull/42), [#43](https://github.com/CLDMV/wol-proxy/pull/43)). The two Dependabot PRs touched the same lockfile entries, one per package group, and together they produce the single change set above.
- **Transitive packages in the same bump**: `vite` 8.3.1 → 8.3.2, `rolldown` and its platform bindings 1.2.11 → 1.2.12, `@oxc-project/types` 0.151.0 → 0.152.0, and `why-is-node-running` 3.2.2 → 3.2.1 (the exact version Vitest 5.0.3 depends on, so this one moves down).
